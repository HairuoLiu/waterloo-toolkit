# 滑铁卢入学 SOP · 使用说明与资料

> 一句话用法：**按阶段从上往下走** —— 行前 → 抵达 → 注册 → 学术生活，每一步照着清单做；遇到问题先搜关键词，解决后到底部「踩坑记录」追加一条。

---

## 一、核心概要

给**滑铁卢大学新生（以研究生 MEng / Co-op 为主）**的入学全流程 Wiki。

- **解决什么**：入学要办的事散落在学校十几个页面里，本页把它们压成一条**四阶段时间线**，每步给可执行清单。
- **怎么用一句话**：从上往下按阶段推进，边做边打勾；不确定的信息用顶部搜索框搜；踩过的坑追加到页面底部，它会成为你自己的「入学战地笔记」。

---

## 二、怎么用

| 区块 | 说明 |
|------|------|
| 顶部 Hero | 一页定位 + 5 条能力药丸（四阶段 / 清单 / 踩坑记录 / 目录搜索 / 整理日期） |
| ① 总览 | 四个阶段的速览，先建立整体时间感 |
| ② 行前 | 签证、住宿、机票、资金、材料清单 |
| ③ 抵达滑铁卢 | 落地后先办什么（银行卡、电话卡、SIN、交通） |
| ④ 注册 | Quest / LEARN / 选课 / 学生卡等 |
| ⑤ 学术与日常生活 | 上课、TA、医保、日常 |
| ⑥ 重要日期速查 | Fall 2026 关键节点 |
| ⑦ Co-op 求职时间线 | 何时投、何时面、WaterlooWorks 节奏 |
| ⑧ 租房指南 | 区域、渠道、签约避坑 |
| ⑨ 选课策略 | 与 `course-planner` 联动 |
| ⑩ 研究生杂费明细 | 费用构成 |
| ⑪ 踩坑记录 / 更新日志 | **由 `data.js` 驱动**，追加一条即自动渲染 |

**交互**
- **左侧目录**（`#side-toc`）：滚动自动高亮当前章节；搜索时每项显示命中数徽标。
- **全文搜索**（`#sop-search`）：命中处金色高亮；**未命中的章节自动整节隐藏**；`#sop-clear` 清空；`#sop-status` 显示「命中 N 处 · M 个章节」。
- **锚点直达**：`#top` `#overview` `#pre` `#arrive` `#enroll` `#life` `#dates` `#coop` `#housing` `#courses` `#fees` `#log`。

## 三、怎么设计

**文件清单**

| 文件 | 职责 |
|------|------|
| `index.html` | 11 个章节的长文正文 + 顶栏 + 目录容器 + 搜索框 + toast |
| `app.js` | 目录生成与滚动高亮、全文搜索（高亮 / 隐藏 / 计数）、踩坑记录渲染、toast、分享 |
| `data.js` | `window.SOP_LOG`：踩坑记录数据源 |
| `cover.svg` | 封面（由 `assets/gen_cover.py` 生成，禁止手改） |
| `AGENT_GUIDE.md` | 给其它 AI 的追加规范（怎么加记录、怎么加章节、红线） |

**数据结构**（`data.js`，追加一条即生效）
```js
window.SOP_LOG = [
  { date: "2026-09-02", tag: "建站", title: "一句话标题", body: "详情；换行用 \n" }
];
```
- `date`：`YYYY-MM-DD` 或阶段标签（如 `"行前 / 抵达 / 注册"`）
- `tag`：分类（签证 / 银行 / 选课 / 住宿 / 医保 …）
- `title` / `body`：一句话标题与详情

**渲染流程**：`DOMContentLoaded` → 生成目录 → 绑定搜索 → 由 `SOP_LOG` 渲染 `#sop-log` → 绑定滚动高亮与分享。

**依赖**：无第三方库、无 CDN；样式全部来自 `../../assets/style.css`。

## 四、怎么改

| 想改什么 | 动哪里 | 改完怎么验证 |
|---|---|---|
| 追加一条踩坑记录 | `data.js` 的 `SOP_LOG` 数组加一个对象 | 打开页面滚到底部，新条目出现在日志最上方/列表里 |
| 改正文某一段 | `index.html` 对应 `<section id="...">` | 搜索该段关键词应命中；目录跳转正确 |
| 新增一个章节 | `index.html` 加 `<section id="x">` + 目录项 | 目录出现、滚动高亮、搜索隐藏逻辑对该章节生效 |
| 改搜索行为（高亮/隐藏） | `app.js` 的搜索与 `matches` 逻辑 | 输入关键词后：未命中章节消失、命中数徽标正确 |
| 改章节标题文案 | **`index.html` 与 `app.js` 目录生成处需同步** | 目录文字与正文标题一致 |

> 改了行为 / 数据 / 结构 ⇒ **同一次提交必须更新本文件**（见根 `README.md` 的 R2）。

## 五、事实红线

- 日期、金额、电话、邮箱、URL、课号**一律原样保留并可溯源，绝不编造**；拿不到就明确标注「平台消息 / 网站表单」。
- 属于推断的内容**必须显式标注「推断」**。
- 引用校方政策时附官方链接与检索日期。
- 双语改造后：新增文案必须**中英两种都补**，缺一语言视为缺陷。
