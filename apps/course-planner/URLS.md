# 滑铁卢大学 · 学生常用官方 URL 清单

> 维护说明：本清单供「常用站点」导航栏与未来任何 AI 会话取用。**加 / 删 / 改 URL 时，必须同步更新 `index.html` 顶栏 `.ext-menu` 里对应的 `<a>` 标签。**
> 数据来源：UW 官方「Student resources」页与「Offices and Services」页（`uwaterloo.ca`）。URL 如有失效，以官网为准。

## ① 学习 · 选课（核心，工科/理科生每天都用）

| 名称 | URL | 用途 |
|---|---|---|
| **Quest** | https://quest.uwaterloo.ca | 选课/退课、缴费、课表、成绩、税务单据、学生档案 —— 学生信息系统总入口 |
| **LEARN** | https://learn.uwaterloo.ca | 课件、作业提交、成绩、课程讨论（Brightspace 平台） |
| **Classes** | https://classes.uwaterloo.ca | 全校课程时间表查询（按学期/科目/教室） |
| **Schedule of Classes** | https://uwaterloo.ca/graduate-studies-postdoctoral-affairs/graduate-studies-calendar/schedule-classes | 研究生课程排课总表（Quest 之外的另一查法） |
| **Academic Calendar** | https://uwaterloo.ca/academic-calendar/graduate-studies/catalog | 学位要求、学术日历、重要日期（研究生版） |
| **outline** | https://outline.uwaterloo.ca | 历年课程 syllabus / 授课安排 / 讲师 / 先修（按课号直达） |
| **OD（Open Data）课程查询** | https://odyssey.uwaterloo.ca | 课程与大纲查询（Odyssey 课程数据门户） |
| **Odyssey（研究生系统）** | https://odyssey.uwaterloo.ca | 研究生记录、里程碑、毕业流程（研究生专用） |

## ② 身份 · 账号（出问题先来这里）

| 名称 | URL | 用途 |
|---|---|---|
| **Portal** | https://portal.uwaterloo.ca | 一站式门户：注册/缴费/课表/通知聚合，含地图、订餐、校园服务 |
| **WatIAM** | https://watiam.uwaterloo.ca | 改密码、密保邮箱、账号管理 |
| **2FA 双因子** | https://uwaterloo.ca/two-factor-authentication | 双因子认证设置（Quest 等核心服务强制要求） |
| **Office 365 邮件** | https://mail.uwaterloo.ca | 学校邮箱（`用户名@uwaterloo.ca`） |
| **WatCard** | https://uwaterloo.ca/watcard | 学生卡：门禁、餐饮、打印、借书 |
| **eduroam** | https://uwaterloo.ca/ist/wifi | 校园 Wi-Fi 配置 |
