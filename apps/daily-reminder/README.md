# 研究生每日提醒 · 使用说明与资料

> 一句话用法：**每天看一眼「今日一件事」**，需要发给同学就点复制；想知道未来一段时间有什么，切月历视图按学年翻。

---

## 一、核心概要

把**滑铁卢大学研究生重要日期**做成可查、可筛选、可转发的日历。

- **给谁**：UW 研究生（尤其是刚入学、还不熟悉校历节奏的新生）。
- **解决什么**：校方重要日期页面是长表格，看不出「今天该做什么」；本工具把它转成日历 + 提醒 + 一键复制文案。
- **怎么用一句话**：每天打开看顶部提醒，按类别筛选自己关心的（缴费 / 退课 / 考试 / 假期…），需要同步给同学就复制文案发群。

---

## 二、怎么用

| 功能 | 位置 / 用法 |
|------|-------------|
| **双视图切换** | 顶部「月历 / 列表」。月历默认；跨天事件整段底色延续 |
| **学年拆分** | 顶部「选择学年」tab，每个学年（Fall 入学为起点，如 2026–2027）独立成一套日历/列表/提醒，互不混淆 |
| **类别筛选** | 缴费 / 退课 / 考试 / 假期 / 迎新 / 成绩 …，两视图共用 |
| **今日 / 本周 / 本月提醒** | 顶部三段提醒区，`pickFocus` 按优先级与临近程度挑「最该做的一件事」 |
| **一键复制** | 「复制」按钮把提醒文案写入剪贴板，可直接发群 |
| **点日期看详情** | 月历点某天、列表点某行 → 弹出当日/该事件**中英双语**详情 |

**数据范围**：只保留「今天及以后、且属于 Fall 入学学年」的节点。校方目前只发布到 **2027 春季**（2026–2027 学年结束），所以现在只有 **2026–2027** 一个学年 tab。

## 三、怎么设计

**文件清单**

| 文件 | 职责 |
|------|------|
| `index.html` | 页面骨架（顶栏、学年 tab、视图切换、筛选条、提醒区、月历/列表容器、详情弹层、toast） |
| `app.js` | 全部逻辑：数据加载、学年切分、两种视图渲染、筛选、提醒计算、复制、分享 |
| `data.js` | `window.UW_EVENTS`：事件数据源（内联，避免 fetch 本地文件限制） |
| `cover.svg` | 封面（`assets/gen_cover.py` 生成，禁止手改） |

**数据结构**（`data.js`）
```js
window.UW_EVENTS = [
  {
    "title_en": "Labour Day",
    "title_zh": "劳动节 (Labour Day)",
    "category": "假期",        // 决定配色与筛选归类
    "emoji": "🎉",
    "priority": 0,             // 数字越小越优先（提醒时会优先挑）
    "term_en": "Fall 2026",
    "term_zh": "秋季 2026",
    "start": "2026-09-07",     // ISO 日期
    "end": "",                 // 跨天事件填结束日期，留空=单日
    "action": "全校停课、办公室关闭，享受假期吧～",  // 中文行动建议（无后缀=中文）
    "action_en": "No classes and offices closed; enjoy the holiday.",
    "desc_en": "No classes and offices closed.",
    "academicYear": 2026       // ★ 学年分片的依据
  }
];
```

**双语取值约定（`app.js` 的 `lpick`）**：`字段_当前语言` → `无后缀原字段` → `字段_另一语言`。
「无后缀原字段」必须排在「另一语言」之前 —— 本数据集存在「原字段=中文 + `*_en`=英文」的字段（如 `action` / `action_en`），顺序颠倒会导致**中文模式反而显示英文**。

**关键函数**（`app.js`）

| 函数 | 作用 |
|------|------|
| `loadEvents` | 读取 `UW_EVENTS` 并按 `academicYear` 分组 |
| `presentYears` | 渲染学年 tab |
| `eventsOnDay` / `isOngoing` | 判定某天命中哪些事件（含跨天） |
| `pickFocus` | 按 `priority` + 临近程度挑「今日一件事」 |
| `renderCalendar` / `renderTable` | 月历 / 列表两种渲染 |
| `buildMessage` / `buildRangeSummary` / `copyText` / `copyRange` | 生成与复制提醒文案 |
| `hexToRgba` | 类别配色（把主题色转成半透明底色） |

**依赖**：无第三方库、无 CDN；样式来自 `../../assets/style.css`。

## 四、怎么改

| 想改什么 | 动哪里 | 改完怎么验证 |
|---|---|---|
| 加 / 改一个日期节点 | `data.js` 的 `UW_EVENTS` | 切到对应学年，月历与列表都应出现；提醒文案随优先级变化 |
| 加一个新学年 | 给数据补 `academicYear` 字段 | 顶部自动多出一个学年 tab（**无需改代码**） |
| 加一个类别 | `data.js` 用新 `category` + `app.js` 的类别配色/映射表 | 筛选条出现新类别、卡片配色正确 |
| 改「今日一件事」的挑选逻辑 | `app.js` 的 `pickFocus` / `weight` | 构造几条不同 priority 与日期的事件，确认挑中的是预期那条 |
| 改提醒文案模板 | `buildMessage` / `buildRangeSummary` | 点复制，粘贴出来检查排版 |
| 改配色 | `style.css` 与 `app.js` 的 `hexToRgba` 取色处 | 月历底色与筛选条颜色一致 |

> 改了行为 / 数据 / 结构 ⇒ **同一次提交必须更新本文件**（见根 `README.md` 的 R2）。

## 五、事实红线

- 日期、金额、截止日、URL **一律照抄校方原文，绝不编造**；来源不明的写「待核实」。
- `action` 里的行动建议属于**推断**时，必须显式标注「推断」。
- 每条事件应能回溯到 `uwaterloo.ca/important-dates/graduate`；新增数据请带**检索日期**。
