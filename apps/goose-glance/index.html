Goose Glance for WaterlooWorks

AI-powered job-posting insight, right inside Waterloo Works

What is it?

Goose Glance is an open-source (MIT) Chrome extension. It reads Waterloo Works job pages and, using an in-browser AI model (WebLLM — no server, no data upload), condenses long postings into an "insight card":

  • AI-generated job title + 1–3 key responsibilities (keywords highlighted)
  • Work-term length, location (city/province/country) + remote / hybrid / on-site
  • Company, required skills (technical / language / framework / soft)
  • Special requirements (French, driver’s license, background check, citizenship/PR, foreign visa, certs) & required docs (resume, co-op history, cover letter, grades, portfolio)
🛒 Install on Chrome Web Store ⭐ View Source (GitHub)
